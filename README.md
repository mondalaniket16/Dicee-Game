# 🎲 Dicee Game

A fun and interactive dice game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

🔗 https://dicee-game-sigma.vercel.app

## ✨ Features

- 🎲 Random dice rolls on button click
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔊 Dice rolling sound effects
- 🎞️ Dice shake animation
- 📱 Responsive and clean UI

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📂 Project Structure

```text
Dicee-Game/
├── index.html
├── styles.css
├── script.js
├── images/
└── Sounds/
```

## 🎮 How to Play

1. Open the game.
2. Click the **Roll Dice** button.
3. The dice roll randomly.
4. The player with the higher number wins.
5. If both dice show the same value, it's a draw.
